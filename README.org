* Lavu Scheme
Lavu stands for lavender, good plant.

** Project Goals
Lavu (Lavender) Scheme is an educational R5RS Scheme implementation focused on:
- Maximum comprehensibility through tiny, well-defined passes
- Excellent REPL experience with advanced inspection features
  - we reedline maxing up in this bitch
- Support for type inference and analysis
- Ability to query procedures and values for their types with =? expr...=
- Support the whole R5RS standard
- Ideally, it should also be trivial to bind Rust stuff into the Scheme

** Implementation Philosophy
- Take tiny steps with well-defined scope
- Prioritize inspectability over performance
  - No optimizations at all
- Build strong foundations for type analysis
- Create a learning tool rather than a production compiler

** Architecture
- Stable datum parser and surface classifier with small, inspectable
  normalization steps
- Native Rust evaluator and standard library
- Primitive metadata with predicate refinements for occurrence typing
- Type inference via constraints, branch-sensitive unions, and
  predicate-based refinements

** Compiler Passes
The old numbered parser/AST files explored tiny pass boundaries but led
to repeated whole-tree enum duplication. The active implementation now
uses stable =Datum= and surface expression types, with tiny lowering
steps over shared data structures. The inactive numbered prototype files
have been removed from the source tree; their intended pass boundaries
are recorded here instead.

*** Identification Passes
1. (x) Identify symbol literals (Quote + Identifier)
2. (x) Identify core special forms (lambda, if, set!, begin, quote)
3. (x) Identify let (regular form)
4. (x) Identify named let (separate from regular let)
5. (x) Identify letrec and let*
6. (x) Identify cond and case
7. (x) Identify do
8. (x) Identify and & or
9. (x) Identify delay
10. (x) Identify internal defines

*** Rewrite Passes
11. Rewrite case into cond
12. Rewrite cond into if
13. Rewrite do into letrec
14. Rewrite named let into letrec + lambda
15. Rewrite letrec into let + set!
16. Rewrite let* into nested lets
17. Rewrite regular let into lambda
18. Rewrite delay into (make-promise <lambda>)
19. Rewrite quasiquote
20. Rewrite and & or into if
21. Handle internal defines

** Type System
- (Done, growing) Occurrence typing with constraints
- (Done, growing) Type inference for procedure parameters and return values
- (Done) Type queries in the REPL via =? expr...=
- (Done) Predicate-shaped displayed types and unions, for example
  =(U number? string?)=
- (Done) =set!= assignment constraints maintain type safety

** REPL Features
- (Done) =?= query prefix to show inferred types for expressions and procedures
- (Done) Syntax highlighting and enhanced UI via reedline
- (Done, growing) Rich error messages with source locations via Ariadne
- (Done) Type query display as =value : type-info=, with evaluated
  values isolated from persistent REPL state
- (Done) =??= inference stepper: walk the engine's steps one at a time
  with =←=/=→= (=space=/=enter=/=esc= leaves the final type), re-tracing a
  previously defined name's definition
- (Planned) Inspection of evaluation steps

** R5RS Compliance
- (In progress) Full support for R5RS special and derived forms
- (Done, growing) Top-level/local =syntax-rules= expansion
- (Done, growing) R5RS macro hygiene
- (In progress) Native Rust standard library with type metadata
- (Added) SISC R5RS pitfall fixture under =tests/fixtures/r5rs= with an
  ordinary regression runner
